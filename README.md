Up to 15 posts from [@TekiiiMP](https://x.com/TekiiiMP), each a quote of or a direct reply to a different post of [@makefunai](https://x.com/makefunai) from the pool (status id at or above 2125053632605196760), each carrying make.fun / @makefunai and the play code `makefun-koala-cupcake-viola`.

Score = 2 points per repost, 2 per quote, 1 per like, summed over all posts. Views and replies count nothing.

## Run

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POSTS.json` to the output directory. That is all it does — the house reads the posts themselves from X.
